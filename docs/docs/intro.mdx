# MaxxPro へようこそ

**MaxxPro** は、災害時や日常の備蓄品を効率的かつ安全に管理するための Windows 11 向けデスクトップアプリケーションです。

最新の **WinUI 3 (Windows App SDK)** と **.NET 10** を基盤に開発されており、ローカル第一（Local-First）設計を徹底しています。外部のオンラインデータベースやクラウドサービスに一切依存せず、すべてのデータをお手元のPC内に完結して保存・処理します。

さらに、**Ollama** を通じたローカルAIアシスタント「**Cougar**」を標準搭載。プライバシーを完全に守りながら、自然言語での備蓄確認や対話型の在庫登録・更新を行えます。

---

## 主な特徴

### 1. 完全ローカル・ゼロクラウド設計
- インターネット接続がないオフライン環境や、災害による通信障害時でも100%すべての機能が動作します。
- 備蓄データは端末内のローカル SQLite データベース（`Caiman.db`）に暗号化および安全に保存されます。

### 2. 体系的な3段階分類と保管場所管理
- **大分類 > 中分類 > 小分類** の3階層によるカテゴリ構造で、食料品、飲料水、生活用品、医薬品などをすっきり整理。
- **保管場所（Places）** ごとの在庫数把握や、賞味期限・消費期限（Expiring Date）のトラッキングが可能です。

### 3. ローカルAIアシスタント「Cougar」
- ローカルLLM（**Gemma 4**）およびローカル埋め込みモデル（**EmbeddingGemma**）と連携。
- ベクトル検索エンジン（**sqlite-vec**）による会話履歴の永続化。
- **ヒューマンインザループ（Human-in-the-Loop）** による安全設計：AIによるデータの追加・更新・削除は、ユーザーが画面上で明示的に「許可」した場合にのみ実行されます。

### 4. Windows 11 ネイティブの洗練されたUI
- **Mica バックカラー**、Fluent Design System、ダークモード・ライトモードの自動切替に対応。
- 日本語（ja-JP）および英語（en-US, en-GB）の多言語対応。

## システム要件

| 項目 | 要件 |
| :--- | :--- |
| **OS** | Windows 11 (バージョン 22H2 以降推奨, 64-bit) |
| **ランタイム** | .NET 10.0 ランタイム（自己完結型パッケージの場合は不要） |
| **AI機能（任意）** | [Ollama](https://ollama.com/) がインストールされ、ローカルで稼働していること |
| **推奨AIモデル** | `gemma4:e2b` (対話用), `embeddinggemma:latest` (埋め込み用) |

:::tip AI機能なしでも通常利用が可能
Ollama がインストールされていない環境でも、手動での品目・保管場所・分類の登録・編集・管理機能はすべて問題なくご利用いただけます。
:::
