# Storage Places (Places)

A critical principle in disaster preparedness is **geographic diversification** of stockpiles. Keeping all supplies in one spot poses risks if a room becomes inaccessible.

MaxxPro allows you to register and track multiple storage locations (**Places**).

---

## Recommended Storage Locations

- **Kitchen / Pantry**: Ideal for "rolling stock" items consumed and replenished in daily routine.
- **Front Door / Bedroom**: Ideal for primary evacuation bags (Go Bags) needed within seconds.
- **Garage / Shed**: Ideal for bulk goods (tents, gas stoves, large water containers).
- **Vehicle Trunk**: Supplies for travel disruptions or vehicle-based evacuation.

---

## Monitoring Place Inventory

The Places view displays each storage location alongside **`ItemsCount`** (the total number of items currently stored there), helping you ensure supplies are evenly distributed across your home or facility.
