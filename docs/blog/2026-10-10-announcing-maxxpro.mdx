本日、Windows 11 向け備蓄管理デスクトップアプリケーション **MaxxPro 1.0** を公開いたしました！

MaxxPro は、災害対策や日々の備えを効率的かつ確実に管理するために開発されたオープンソースソフトウェアです。「**ゼロクラウド・完全ローカル動作**」を掲げ、すべてのデータを手元のPC内に保持しながら、最新のローカルAI技術を安全に活用できます。

{/* truncate */}

## 開発の背景：なぜローカルファーストなのか？

自然災害（地震・台風・大規模停電など）が発生した際、最も必要とされる備蓄情報ですが、**インターネット回線の途絶やクラウドサービスの停止によって閲覧できなくなるリスク** があります。

また、家庭内の食料・飲料水・医薬品などの保管場所や在庫数は、高度なプライバシー情報でもあります。外部のサーバーにデータを預けることなく、自分のPC上だけで完結して管理できる安心感を大切にしました。

## MaxxPro の主なハイライト

### 1. 外部データベース不要の完全ローカル設計
MaxxPro は、Entity Framework Core 10 と SQLite（`Caiman.db`）を採用。クラウドやオンライン認証を一切介さず、オフライン環境でもすべての機能が軽快に動作します。

### 2. 3段階の分類階層と保管場所管理
- **大分類 > 中分類 > 小分類** による柔軟な階層化。
- パントリー、玄関脇の防災リュック、車載など、保管場所（Places）ごとに品目数や消費・賞味期限をトラッキング。

### 3. ローカルAIアシスタント「Cougar」
ローカル推論基盤 **Ollama**（`gemma4:e2b` / `embeddinggemma`）と `sqlite-vec` を連携。
自然言語で「今年期限が切れる品物は？」と尋ねたり、備蓄の追加を依頼できます。データベースの変更ツールを実行する際は、**画面上でユーザーの許可（Approve）を必須とする安全機能** が組み込まれています。

### 4. 洗練された Windows 11 ネイティブデザイン
WinUI 3 と Windows App SDK 1.7 を基盤とし、Mica バックドロップと Fluent Design による直感的なUIを提供します。
