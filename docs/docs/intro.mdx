# MaxxPro へようこそ

**MaxxPro** は、災害時や日常の備蓄品（ストックパイル）を安全かつ確実に管理するための Windows 11 向けデスクトップアプリケーションです。

**WinUI 3 (Windows App SDK 2.5)** と **.NET 10** を基盤に開発されており、徹底した**ローカル第一（Local-First / Zero-Cloud）**原則を採用しています。外部のオンラインデータベースやクラウドサービスに依存せず、インベントリデータを端末のローカルストレージに保存します。

さらに、[Ollama](https://ollama.com/) と連携するローカルAIアシスタント「**Cougar**」を搭載しています。Ollama と必要なモデルを用意すると、自然言語による備蓄品の問い合わせや、承認付きの登録・更新操作を端末内で実行できます。

---

## 主な特徴

### 1. 完全ローカル・ゼロクラウド設計
- インターネット接続が利用できないオフライン環境でも、手動での備蓄管理機能をローカルで利用できます。
- 備蓄データは Windows アプリケーションの分離されたローカル領域（`LocalFolder`）内の SQLite データベース（`Caiman.db`）に保存されます。

### 2. 体系的な3段階分類と保管場所管理
- **大分類 > 中分類 > 小分類**（`LargeCategory` > `MediumCategory` > `SmallCategory`）の階層構造により、食料品、飲料水、生活用品、医薬品などを論理的に整理できます。
- **保管場所（Places）** ごとに品目を分散管理し、賞味期限・消費期限（`Life`）を一覧で確認できます。

### 3. ローカルAIアシスタント「Cougar」
- 既定ではローカルLLM（`gemma4:e2b`）およびローカル埋め込みモデル（`embeddinggemma:latest`）を Ollama 経由で利用します。
- Ollama のポート、チャットモデル、埋め込みモデルはアプリの設定画面から変更できます。
- `sqlite-vec` を用いたベクトル検索ストレージ（`chathistory.db`）により、会話コンテキストを端末内に永続化。
- **ヒューマンインザループ（Human-in-the-Loop）** による安全弁：データの追加・変更・削除を伴うAIツール操作は、画面上でユーザーが明示的に「許可」した場合のみ実行されます。

### 4. Windows 11 ネイティブの洗練されたUI
- **Mica バックドロップ** と Fluent Design System に準拠したモダンデザイン。
- システムのライトモード / ダークモード設定への自動追従。
- 多言語ローカライズ対応（日本語 `ja-JP`、英語 `en-US` / `en-GB`）。

## システム要件

| 項目 | 要件 |
| :--- | :--- |
| **オペレーティングシステム** | Windows 11 (ビルド 22000 以降、ビルド 26100+ 推奨、64-bit / ARM64) |
| **ランタイム** | .NET 10.0 ランタイム（自己完結型パッケージの場合は同梱） |
| **ローカルAI（任意）** | [Ollama](https://ollama.com/) (Windows版、バックグラウンド稼働) |
| **既定AIモデル** | `gemma4:e2b`（チャット対話用）、`embeddinggemma:latest`（ベクトル埋め込み用） |

:::tip AI機能なしでも通常利用が可能
Ollama がインストールされていない、あるいは停止している環境でも、手動での品目・保管場所・分類の登録・編集・管理機能はすべて問題なくご利用いただけます。
:::
