# クイックスタートガイド

このガイドでは、MaxxPro のインストールから初期データ登録、およびローカルAIアシスタントの有効化までの手順を解説します。

---

## ステップ 1: アプリケーションの入手とインストール

1. [MaxxPro リリースページ](https://github.com/Tayra-Sakurai/MaxxPro/releases) から最新の `.msixbundle` または `.msix` パッケージをダウンロードします。
2. 配布パッケージに付属の証明書（`.cer`）を「信頼されたルート証明機関」にインポートします（サイドロード環境の場合）。
3. インストーラーを実行してインストールを完了します。

---

## ステップ 2: 保管場所（Places）の作成

備蓄品を登録する前に、まず品物を保管する場所を定義します。

1. 左側ナビゲーションメニューから **「保管場所 (Places)」** を選択します。
2. 画面上部の **「追加 (Add Item)」** ボタンをクリックします。
3. 保管場所の名称を入力します（例: `パントリー`、`玄関脇防災リュック`、`北側物置`、`冷蔵庫`）。
4. **「保存 (Save)」** をクリックして登録を確定します。

---

## ステップ 3: 分類（Categories）の作成

MaxxPro では、**大分類 > 中分類 > 小分類** の3段階でアイテムを整理します。品目（Item）は小分類に紐づきます。

1. 左側メニューから **「分類 (Categories)」** を選択します。
2. まず **大分類** を追加します（例: `非常用食料`、`生活日用品`、`医療・救急`）。
3. 登録した大分類の下に **中分類** を作成します（例: `保存食・レトルト`、`飲料水`）。
4. 最後に中分類の下に **小分類** を作成します（例: `アルファ米`、`カンパン`、`2Lペットボトル水`）。

---

## ステップ 4: 備蓄品目（Items）の登録

保管場所と分類が用意できたら、実際の備蓄品を登録しましょう。

1. 左側メニューから **「品目 (Items)」** を選択します。
2. **「追加 (Add Item)」** ボタンをクリックします。
3. 以下の情報を入力します：
   - **名称 (Name)**: `五目ごはん アルファ米 100g`
   - **説明 (Description)**: `スプーン付き、熱湯15分または水60分`
   - **期限 (Expiring Date)**: 賞味期限・消費期限の日付を選択
   - **大分類 / 中分類 / 小分類**: 作成済みの分類を選択
   - **保管場所 (Place)**: 保管場所を選択
4. **「保存 (Save)」** をクリックします。テーブル一覧に追加され、期限順や場所ごとに管理できるようになります。

---

## ステップ 5: ローカルAIアシスタント「Cougar」の準備（任意）

自然言語で備蓄を調べたり更新したい場合は、ローカルAI環境を立ち上げます。

### 1. Ollama のインストール
[Ollama 公式サイト](https://ollama.com/) から Windows 版をダウンロードしてインストールします。

### 2. 必要なモデルの取得
PowerShell またはコマンドプロンプトを開き、以下のコマンドを実行します：

```powershell
# チャット用モデルのダウンロード
ollama pull gemma4:e2b

# ベクトル検索・会話メモリ用モデルのダウンロード
ollama pull embeddinggemma:latest
```

### 3. MaxxPro でセッションを開始
1. MaxxPro の左側メニューから **「チャット (Chat)」** を選択します。
2. 上部の **「セッション開始 (New Session)」** をクリックします。
3. メッセージ欄に「`賞味期限が近い備蓄品は何がありますか？`」や「`パントリーにある備蓄品一覧を教えて`」と入力して送信します。
4. AIがデータベースの変更ツールを実行しようとする場合は、画面に **承認ダイアログ** が表示されます。内容を確認し、問題なければ **「許可 (Approve)」** をクリックします。
