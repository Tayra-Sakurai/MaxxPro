# 品目管理 (Items)

備蓄品の一覧確認、新規追加、編集、削除、および賞味期限の管理について解説します。

---

## 品目のデータ構造

MaxxPro に登録される各品目（`Item`）は、以下の属性を保持します：

| 属性 | 説明 | 必須 | 例 |
| :--- | :--- | :---: | :--- |
| **ID** | システムによって自動採番される一意の識別番号 | 自動 | `1`, `2` |
| **名称 (Name)** | 品目の具体的な商品名や名称 | ○ | `長期保存水 2L` |
| **説明 (Description)** | 備考、特記事項、アレルギー情報、入数など | - | `6本入り 1ケース 箱ごと保管` |
| **期限 (Expiring Date)** | 賞味期限または消費期限 | ○ | `2029-05-31` |
| **小分類 (Category)** | 所属する小分類（大分類・中分類と階層連動） | ○ | `保存水` |
| **保管場所 (Place)** | 実際に保管している場所 | ○ | `北側パントリー下段` |

---

## 操作手順

### 品目の新規追加
1. メニューの **「品目 (Items)」** 画面を開きます。
2. コマンドバーの **「追加 (Add Item)」** をクリックします。
3. 名称、説明、期限日を入力します。
4. ドロップダウンから大分類を選択すると、紐づく中分類が絞り込まれ、続いて小分類が選択可能になります。
5. 保管場所を選択し、**「保存 (Save)」** をクリックします。

### 品目の編集
1. テーブル一覧から編集したい行を選択します。
2. コマンドバーの **「編集 (Edit)」** をクリックします。
3. 内容を変更し、**「保存 (Save)」** をクリックします。

### 品目の削除
1. 削除したい品目を選択します。
2. コマンドバーの **「削除 (Delete)」** をクリックします。

### データの同期
手動または別プロセス等でデータベースに変更が生じた場合、コマンドバーの **「同期 (Sync)」** をクリックすると最新の状態がテーブルに再読込されます。
