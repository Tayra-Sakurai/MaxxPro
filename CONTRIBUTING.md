# Contributing to MaxxPro

Welcome to our repository! And thank you for your interest to contribute to this repository.

To maximize the number of contributors, this repository must be organized. So please follow this contributing rules to keep this repository organized.

## Issues and Discussions

Please add issues and discussions with taking care of relations to others.

## How to Contribute

Please follow the steps in this file.

### Step 1: Find or Create Open Issues

Please search for the issues and/or discussions related to your planning contribution.
Then please leave a comment to them about your plan of contribution and how the contribution fixes the issue(s) and/or discussion(s).

Please add a new issue or discussion related to ones related to your contribution if you find a drafted pull request or related branch linked to the issue(s) and/or discussion(s).
Since you must close them when your pull request has been merged, each unique pull request must have unique linked issue(s) and/or discussion(s).

### Step 2: Fork and Make a New Branch

Please **fork** this repository's `master` branch and make a **new branch** on your forked repository.

Please follow the following nomenclature of branches:

#### Nomenclature of Branches

The basic name structure of **AI aided** branch is:

```text
[type-prefix]/[ai-agent-name]/[pull-request-title]
```

The name structure of **non-AI aided** branches is:

```text
[type-prefix]/[pull-request-title]
```

##### Type Prefixes

You must choose one of the following type prefix to express the abstract kind of your modification.

| Prefix | Description |
|:-:|:-|
| `fix` | Modifications for fixing reported bug. |
| `feat` | Modifications to add new feature to this application. |
| `docs` | Updates of documentations (such as `README.md`). |
| `ref` | Code refactoring without behavior changes. |
| `test` | Updates or additions of tests. |

##### AI Agent Name

You must specify the AI agent name which you mainly used in the branch name.

e.g. `fix/codex/fixed-unexpected-shutdown`

### Step 3: Draft a Pull Request

Please make a draft of a Pull Request before modifying any source codes.
Please save the draft and add comments while you are contributing.

### Step 4: Modify the Source Code

Please modify source code in the forked branch.
Please use the line delimiters of `CRLF` because this application software is intended for uses on Windows.

### Step 5: Make Pull Request

Please fill all fields in the PR template and submit the Pull Request.

Your contribution will be merged to the `master` branch when your PR is approved.
