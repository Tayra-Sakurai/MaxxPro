# 保管場所管理 (Places)

災害対策における重要な鉄則の1つが **「備蓄の分散配置」** です。1箇所にすべての備蓄を集中させておくと、家屋の一部損壊や家具の転倒で取り出せなくなるリスクがあります。

MaxxPro では、保管場所（`Place`）ごとに品目を登録・管理できます。

---

## 保管場所の活用例

- **キッチン / パントリー**: 日常的に消費しながら備蓄する「ローリングストック」用の食料や水。
- **玄関脇・寝室**: 地震直後に即座に持ち出す「一次避難リュック（非常持出袋）」。
- **屋外物置 / トランク**: 長期避難生活用のテント、カセットコンロ、大量の飲料水。
- **車載備蓄**: 車中泊や外出時被災に備えた携帯トイレ、アルミブランケット、非常食。

---

## 画面の見方と機能

- **保管場所一覧**: 登録されている場所の名称と、**該当場所に保管されている品目数（`ItemsCount`）** が一目で確認できます。
- **場所の追加**: 名称を入力して保存するだけのシンプルな操作。
- **場所の削除**: 関連する品目を整理した上で安全に削除できます。
