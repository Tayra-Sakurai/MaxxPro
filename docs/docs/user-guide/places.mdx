# 保管場所管理 (Places)

防災対策における重要な原則の1つが **「分散配置（分散備蓄）」** です。すべての備蓄品を1箇所の物置や押し入れに集中させておくと、地震や家屋の損壊でドアが開かなくなったり、家具の転倒で侵入できなくなった場合に、すべての備蓄が利用不能になるリスクがあります。

MaxxPro では、保管場所（`Place`）を定義し、場所ごとの備蓄状況を管理できます。保管場所は、家庭内の棚や部屋だけでなく、非常持ち出し袋、車載品、職場備蓄などにも使えます。

---

## 画面構成と一覧テーブル

保管場所管理画面（`PlacesView`）は、**保管場所一覧テーブル**、**名称入力パネル**、**コマンドバー**で構成されています。

### テーブルの項目仕様

| 列名 | バインドプロパティ | 説明 |
| :--- | :--- | :--- |
| **ID** | `Place.Id` | データベースで一意に管理される識別番号。 |
| **名称** | `Place.Name` | 保管場所の物理的な呼称（例: `パントリー`, `玄関脇防災リュック`）。 |
| **項目数** | `Place.ItemsCount` | 当該保管場所に現在登録されている品目の合計点数。 |

---

## コマンドバーの操作一覧

| ボタン名 | アイコン | 動作・役割 |
| :--- | :---: | :--- |
| **追加** | ➕ | 入力フォームをクリアし、新しい保管場所の登録状態にします。 |
| **編集** | ✏️ | 一覧テーブルで選択した保管場所の名称を入力パネルに読み込みます。 |
| **テーブルを同期** | 📁🔄 | データベースから保管場所の一覧と最新の品目数（`ItemsCount`）を再取得します。 |
| **削除** | 🗑️ | 現在選択中の保管場所をデータベースから削除します。 |
| **保存** | 💾 | 入力した名称で保管場所を新規作成、または既存の名称を更新します。 |

:::note
`ItemsCount` は関連付けられた品目コレクションから算出されます。表示が古いと感じた場合は **「テーブルを同期」** を実行してください。
:::

## 保管場所の設計・分散備蓄のヒント

効果的な分散備蓄を行うために、用途と時間軸に応じた場所の設定をおすすめします：

1. **キッチン / パントリー（日常ローリングストック）**:
   - 日常的に消費しながら買い足す保存水、レトルト食品、カセットコンロなど。
2. **玄関脇 / 避難経路（一次避難・持ち出し袋）**:
   - 災害発生直後に背負って逃げるための軽量・即応性の高い物資（携帯トイレ、水、ヘッドライト、防寒シート）。
3. **寝室 / ベッド下（就寝時被災対応）**:
   - 夜間の大地震で足元にガラス片が散乱した事態に備えた、厚底スリッパ・軍手・ホイッスル・小型懐中電灯。
4. **屋外納戸 / ベランダ（二次避難・生活維持）**:
   - 在宅避難が長期化した場合に使用する大量の飲料水、簡易トイレ備蓄、カセットガス予備。
5. **車載トランク（外出時・車中泊対策）**:
   - 車中泊や帰宅困難時に役立つアルミブランケット、非常用簡易トイレ、モバイルバッテリー、非常食。

## 命名のおすすめ

- 家族や同僚が見ても分かる物理名にします（例: `キッチン下段右`, `玄関防災リュック`, `車載トランク`）。
- 同じ部屋に複数の保管場所がある場合は、棚番号や方角を入れます。
- 持ち出し用と在宅避難用は分けて登録すると、災害時の判断が速くなります。
