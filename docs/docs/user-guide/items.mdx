# 品目管理 (Items)

品目管理画面では、備蓄品の一覧確認、新規追加、編集、削除、および賞味期限・消費期限の管理を行います。期限が近いものから確認しやすいよう、一覧は期限日と名称を基準に読み込まれます。

---

## 画面構成

品目管理画面（`ItemsView`）は、上部の**データ一覧テーブル**、中央の**編集パネル**、下部の**操作コマンドバー**で構成されています。

```
┌─────────────────────────────────────────────────────────────┐
│  TableView (品目一覧テーブル)                               │
│  [ID] [期限] [大分類] [中分類] [小分類] [名称]             │
├─────────────────────────────────────────────────────────────┤
│  編集パネル                                                 │
│  [大分類 ▼] [中分類 ▼] [小分類 ▼] [期限日 📅]              │
│  [名称 (Name) 入力欄                                      ] │
│  [説明 (Description) 複数行入力欄                         ] │
├─────────────────────────────────────────────────────────────┤
│  コマンドバー                                               │
│  [追加] [編集] [テーブルを同期] | [同期] [削除] [保存]      │
└─────────────────────────────────────────────────────────────┘
```

---

## 一覧テーブルの項目仕様

| 列名 | バインドプロパティ | 説明 |
| :--- | :--- | :--- |
| **ID** | `Item.Id` | データベースで一意に管理される識別番号。 |
| **期限** | `Item.Life` | 賞味期限または消費期限（日付）。期限管理の基準となります。 |
| **大分類** | `Item.Category.Parent.Parent.Name` | 所属する最上位の分類（例: `非常用食料`）。 |
| **中分類** | `Item.Category.Parent.Name` | 所属する中間分類（例: `保存食・主食`）。 |
| **小分類** | `Item.Category.Name` | 所属する末端の分類（例: `アルファ化米`）。 |
| **名称** | `Item.Name` | 品目の具体的な商品名や名称。 |

---

## 入力フォームと連動仕様

- **3階層カテゴリ選択の連動**:
  - 「大分類」を選択すると、その配下に属する「中分類」の選択肢が自動で更新されます。
  - 「中分類」を選択すると、その配下に属する「小分類」の選択肢が自動で更新されます。
  - 品目は必ず**小分類**に紐づく必要があるため、大・中・小すべての指定が必要です。
- **期限日の設定**:
  - カレンダー日付ピッカー（`CalendarDatePicker`）をクリックし、製品パッケージ等に記載された賞味期限・消費期限を選択します。
- **名称の検証**:
  - 名称欄は `ValidationTextBox` により必須検証が行われます。空欄の状態では保存ボタンが無効化されます。
- **説明の入力**:
  - 入数（○個入り）、保管上の注意、調理方法（熱湯○分）、アレルギー情報などを自由に記入できます。

:::note
品目の入力を始める前に、[分類管理](./categories) で小分類まで作成しておく必要があります。分類がない状態では、品目を分類に紐づけて保存できません。
:::

## コマンドバーの操作一覧

| ボタン名 | アイコン | 動作・役割 |
| :--- | :---: | :--- |
| **追加** | ➕ | 入力フォームをクリアし、新規品目の登録準備状態にします。 |
| **編集** | ✏️ | 一覧テーブルで選択した行の品目データを編集パネルに読み込みます。 |
| **テーブルを同期** | 📁🔄 | データベースから最新の品目一覧を再取得してテーブルを再描画します。 |
| **同期** | 🔄 | 現在編集パネルに表示されている品目の関連データをDBから再取得します。 |
| **削除** | 🗑️ | 現在編集対象となっている品目をデータベースから削除します。 |
| **保存** | 💾 | 入力した内容で品目を新規登録、または既存品目を更新します（バリデーションエラーがある場合は無効）。 |

## 登録時の実用例

| 入力欄 | 入力例 | メモ |
| :--- | :--- | :--- |
| **大分類** | `非常用食料` | 食料、水、衛生用品などの大きなまとまり。 |
| **中分類** | `保存食・主食` | 用途や消費タイミングで分けます。 |
| **小分類** | `アルファ化米` | 品目が直接属する分類です。 |
| **期限** | `2031-09-30` | 製品パッケージの賞味期限・消費期限を転記します。 |
| **名称** | `尾西の白飯 100g` | 一覧で識別しやすい名称にします。 |
| **説明** | `5食セット、スプーン付き` | 数量、調理方法、アレルギー、購入メモなどを残します。 |
