# クイックスタートガイド

このガイドでは、MaxxPro のインストールから初期データ登録、およびローカルAIアシスタント「Cougar」の利用開始までを順番に説明します。

---

## ステップ 1: アプリケーションの入手とインストール

1. [MaxxPro リリースページ](https://github.com/Tayra-Sakurai/MaxxPro/releases) から最新の `.msixbundle` または `.msix` パッケージをダウンロードします。
2. サイドロード環境で証明書（`.cer`）が同梱されている場合は、証明書をダブルクリックし、保存場所に「ローカル コンピューター」、証明書ストアに「**信頼されたルート証明機関**」を選択してインポートします。
3. `.msix` または `.msixbundle` をダブルクリックし、「インストール」をクリックしてセットアップを完了します。
4. スタートメニューから **MaxxPro** を起動します。起動時にデータベース（`Caiman.db`）が自動生成されます。

:::tip
通常の品目・分類・保管場所の管理には Ollama は不要です。AI チャットを使う場合だけ、ステップ 5 のセットアップを行ってください。
:::

---

## ステップ 2: 保管場所（Places）の作成

備蓄品目を配置する前に、まずご自宅や職場の保管場所を定義します。

1. 左側のナビゲーションメニューから **「保管場所」**（Places）を選択します。
2. 下部コマンドバーの **「追加」** ボタンをクリックします。
3. 画面下部の「名称」欄に保管場所の名前を入力します（例: `パントリー`, `玄関脇非常持出袋`, `北側納戸`, `車載トランク`）。
4. コマンドバーの **「保存」** ボタンをクリックします。
5. 上部の一覧テーブルに登録した保管場所が表示されます。

---

## ステップ 3: 分類（Categories）の作成

MaxxPro では、**大分類 > 中分類 > 小分類** の3段階ツリーで物資を体系化します。**品目は必ず小分類に紐づけられます**。

1. 左側メニューから **「分類」**（Categories）を選択します。
2. **大分類の登録**:
   - ツリーで何も選択していない状態でコマンドバーの **「追加」** をクリックします。
   - 「名称」欄に大分類名（例: `非常用食料`）を入力し、**「保存」** をクリックします。
3. **中分類の登録**:
   - ツリー上で先ほど作成した大分類（`非常用食料`）をクリックして選択します。
   - コマンドバーの **「追加」** をクリックします（自動的に親の大分類がセットされます）。
   - 「名称」欄に中分類名（例: `保存食・主食`）を入力し、**「保存」** をクリックします。
4. **小分類の登録**:
   - ツリー上で作成した中分類（`保存食・主食`）を選択します。
   - コマンドバーの **「追加」** をクリックします（親の大分類・中分類がセットされます）。
   - 「名称」欄に小分類名（例: `アルファ化米`）を入力し、**「保存」** をクリックします。

:::note
品目は小分類に紐づきます。品目登録の前に、大分類・中分類・小分類を1つずつ作成しておくと入力がスムーズです。
:::

---

## ステップ 4: 備蓄品目（Items）の登録

保管場所と分類が準備できたら、実際の備蓄品目を登録します。

1. 左側メニューから **「品目」**（Items）を選択します。
2. コマンドバーの **「追加」** をクリックします。
3. 入力パネルで以下の項目を設定します：
   - **大分類**: ドロップダウンから大分類（例: `非常用食料`）を選択。
   - **中分類**: 絞り込まれた中分類（例: `保存食・主食`）を選択。
   - **小分類**: 目的の小分類（例: `アルファ化米`）を選択。
   - **期限 (Expiring Date)**: カレンダーピッカーから賞味期限・消費期限の日付を選択。
   - **名称 (Name)**: 商品名（例: `尾西の白飯 100g 5年保存`）を入力（必須）。
   - **説明 (Description)**: 数量やスプーンの有無、備考（例: `スプーン付き、熱湯15分または水60分`）を入力。
4. コマンドバーの **「保存」** ボタンをクリックします。
5. 一覧テーブルに登録した品目が追加され、期限日やカテゴリ階層とともに一覧表示されます。

---

## ステップ 5: ローカルAIアシスタント「Cougar」の準備（任意）

自然言語で備蓄状況を確認したり、対話形式で品目を追加・整理したい場合は、ローカルAI機能をセットアップします。

### 1. Ollama のインストール
[Ollama 公式サイト](https://ollama.com/) から Windows 版インストーラーを取得し、インストールします。通常は `localhost:11434` でバックグラウンド実行されます。

### 2. 必要なモデルの取得
ターミナル（PowerShell）を開き、以下の2つのモデルを取得します：

```powershell
# 対話チャット用 LLM
ollama pull gemma4:e2b

# ベクトル検索・会話メモリ用 埋め込みモデル
ollama pull embeddinggemma:latest
```

### 3. MaxxPro でチャットを開始
1. MaxxPro の左側メニューから **「チャット」** を選択します。
2. 必要に応じて **設定** から Ollama のポート、チャットモデル、埋め込みモデル名を確認します。
3. コマンドバーの **「セッション開始」** ボタンをクリックします。
4. 画面下部のメッセージ入力欄に依頼を入力し、**「送信」** をクリックします：
   - 例: `「現在登録されている分類の一覧を教えて」`
   - 例: `「非常用食料に属する品目は何がある？」`
5. **データの変更を伴う依頼を行う場合**:
   - AIがデータベースの変更ツールを実行しようとすると、チャット画面上部のリクエスト一覧に **「エージェントはツールの使用を要求しています。」** という承認項目が表示されます。
   - 当該リクエストを選択した状態で、コマンドバーの **「許可」** ボタンをクリックすると、AIがデータベースの変更を実行します。

:::caution
AI の登録・更新・削除は、必ず承認内容を確認してから許可してください。承認しない限り、AI はローカルデータベースを変更しません。
:::
